Most scripts I had found online only installed Shadowsocks itself. On a new server, there was still plenty of other work to do.

Yesterday, fed up with all the blocking on Kuandaitong, I wanted to set up an SS server on an Alibaba Cloud server in mainland China. Even with the available scripts, I still had to make all sorts of adjustments manually.

So I wrote this script for a typical Ubuntu Server VPS.

Just two steps:

wget --no-check-certificate https://raw.githubusercontent.com/abc950309/ShadowsocksWizards/master/wizards.sh
sudo bash wizards.sh

You can find the project here:

Main features:

  • Automatically installs shadowsocks-go and asks whether to change the default configuration.
  • Automatically installs Google TCP BBR.
  • Asks for a response type and tunes TCP accordingly.
  • Automatically schedules weekly reboots to prevent lockups after long uptimes.
  • Automatically installs supervisor to manage the daemon.
  • Automatically cleans up cached files.
  • Listens on port 443 by default, taking advantage of the GFW's lighter inspection of common ports to improve speed.
