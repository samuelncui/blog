My ZFS system is a raidz2 array of 8 × 10 TB HDDs, and its read performance has consistently been around 190 MB/s. That is not terribly slow, but at that speed iostat shows disk utilization of only about 25%, while CPU usage is also low, leaving plenty of room for improvement.

After quite a bit of searching online, I found that the zfetch_max_distance parameter might affect read performance. It controls the maximum stream prefetch size, or, you could say, the size of the read buffer (see this documentation).

Using the command echo 67108864 > /sys/module/zfs/parameters/zfetch_max_distance to set this parameter to 64 MB can significantly improve read speed.
