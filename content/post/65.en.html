I found this tutorial online and am reposting it here for future use…
(Works on Windows 7.)

Edit the registry manually:
Create a value under the HKEY_CURRENT_USERS\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers key. Use the program's full path as the value name, and “RunAsInvoker” as the value data.
The program will not trigger a User Account Control prompt as long as it doesn't modify system files or settings! (And you won't have to reduce system security by turning UAC off.)
