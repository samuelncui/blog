最近试图给母上的联想 F41A 装个 Windows 7，可惜它毕竟太老了些，遂改装 Windows Thin PC（教程在此，我爱死原作者了，在此表示感谢！）。

Windows Thin PC 是不附带中文的，需要自己安装。安装中文包之后，使用 iTunes 的时候，有一个问题——字体相当诡异。

这个问题是由 Windows 字体回退造成的。Windows Thin PC的字体并不完整，初始状态下不包含微软雅黑等字体，也不包含与此相关的字体回退。只有一个用于 Unicode 的似乎是 No tofu 的字体。可惜此字体能做的也就只是没有乱码罢了。 iTunes 调用的字体没有包含中文，在进行回退的过程中，会回退到原来的字体上去。造成的后果就是歪歪扭扭，根本不忍直视。

经过 Google 配合本人以10分通过过4级的高（hè）超（hè）英语水平，按照 Microsoft 此文中的指示，找到了注册表中关于回滚的那部分：

  • HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\FontLink\SystemLink

此处有注册表项若干，每个字体一个。

按 Apple 此文所述，iTunes 所用字体应为 “Segoe UI 粗体”和“Segoe UI 常规” ，于是把这两项的回退中按照我手中正常的 Windows 7 电脑更改了。

此操作解决了 UI 中的一部分字体扭曲问题，然而列表等处的问题仍然存在。在半个小时的搜索过后，并没有找到 iTunes 所使用的另外一种字体的具体名称。

所以就把正常电脑中的回滚设置整体导出，导入到目标电脑中，问题解决。
